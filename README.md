# DealBook | Paramount–Warner Bros. Discovery

An interactive, single-page M&A case study exploring the Paramount–Warner Bros. Discovery transaction.

## View locally

Open `index.html` in any modern browser. No build tools, dependencies, or API keys are required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `dealbook-paramount-wbd`).
2. Upload `index.html` and this `README.md` to the repository root. You can drag and drop both files using **Add file → Upload files**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your public website will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/dealbook-paramount-wbd/`

If you use a different repository name, replace `dealbook-paramount-wbd` in the URL with that name.
